# Felicia - Var säljer vi
Det här projektet analyserar försäljningsdata för en e-handelsplattform.

## Genomförande
Intäktsanalys per stad:
- Implementerat kod med `pandas` för att läsa in försäljningsdata från CSV.
- Grupperat data efter stad “city” och summerat de totala intäkterna “revenue”.
- Sorterat och presenterat resultatet för att visa vilka städer som genererar störst intäkt.

## Requirements
För att koden ska fungera krävs följande Python-bibliotek:
- `pandas`
Installerat via terminalen
python3 -m pip install pandas
